# Asset plan

公開版では、外部URL参照をやめて画像をこのフォルダ配下に集約します。

## Planned structure

- `brand/`
  - `logo.png`
  - `president.png`
- `hero/`
  - `hero-main.jpg`
- `works/`
  - `works-01/cover.jpg`
  - `works-01/before-01.jpg`
  - `works-01/process-01.jpg`
  - `works-01/after-01.jpg`
- `sample/`
  - 制作中のみ使用する仮画像

## Rules

1. 実際のOKS施工写真を最優先する
2. サンプル画像は公開前に実写真へ差し替える
3. Before / Process / After を案件単位で管理する
4. 新規案件は横位置の完成写真を必ず1枚確保する
